# Сбитые птички — динамика и вектор

Статический сайт на GitHub Pages. Данные читает **напрямую из Google-таблицы**

## Как это работает

1. `index.html` скачивает CSV из гугл-таблицы прямо в браузере посетителя.
2. Весь расчёт (MA14, недельные тренды, вектор) выполняется в JS на лету.
3. Выбор даты в выпадающем списке перестраивает график «как на тот день» (lookback).

## Таблица данных

- Первый лист, две колонки: `date` (2026-08-01) и `bpla_24h` (число)
- Обновления появляются на сайте с задержкой 1–5 минут (кэш Google)

## Как обновлять данные

Просто допишите новую строку в таблицу.
